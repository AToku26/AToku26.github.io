# Portafolio de André Tokumori

Video, motion graphics, fotografía y proyectos hechos a mano. Publicado en **[atoku26.github.io](https://atoku26.github.io)**.

Hecho con [Astro](https://astro.build). El contenido vive en archivos Markdown dentro de `src/content/` y se publica solo en GitHub Pages cada vez que se suben cambios a `main`.

```bash
npm install     # instalar (la primera vez)
npm run dev     # ver el sitio en http://localhost:4321 mientras editas
npm run build   # construir la versión final en dist/
```

➜ **Lee [GUIA.md](GUIA.md)** para saber cómo agregar proyectos, series de fotos y publicar.

La tipografía Bodoni Moda se distribuye bajo la licencia SIL Open Font License (ver `public/fonts/OFL.txt`).
